■ STRATEGIC BRIEFING — EYES ONLY

This is a turn command simulation. On each round, select ONE ORDER, review its effects, and commit it. The adversary then receives exactly one turn.

Rounds 1–3 build an assessment from imperfect reports. Rounds 4–7 test posture, communications, and adversary perception. From round 8, the crisis continues until both sides physically stand down or war begins.

Warning authorities assess. Senior advisers recommend. National leadership alone directs employment. A fictional origin check validates the resulting directive; it does not create authority.

Any directive is limited to one approved military response. After each exchange, reassess, seek termination, or request renewed direction. ABM interception remains a defensive reaction.

In release review you may instead transfer the operation to W.O.P.R. It will suspend live orders, run the complete war-plan matrix as closed simulations, and end the operation after learning whether escalation can produce victory.
